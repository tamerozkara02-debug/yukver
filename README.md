# MaçaZeka'yı Aktif Etme (API Anahtarı Ekleme)

Merhaba! Bu dosya, MaçaZeka'yı çalıştırmak için gereken API anahtarını nereye ekleyeceğinizi bulmanıza yardımcı olmak için düzenlenmiştir.

**.env Dosyasının Yeri:**

Aradığınız `.env` dosyası, bu `README.md` dosyası ile **aynı klasörde**, yani projenin en üst dizininde yer almaktadır. Aşağıdaki şemada görebilirsiniz:

```
PROJE KLASÖRÜ/
├── .env                  <-- ARADIĞINIZ DOSYA BU
├── apphosting.yaml
├── package.json
├── README.md             <-- ŞU ANDA BU DOSYADAYDINIZ
└── src/
    └── ... (diğer klasörler)
```

**Adım Adım Yapılacaklar:**

1.  Sol taraftaki dosya listesinden `.env` dosyasını bulun ve açın.
2.  İçindeki `YAPI_ANAHTARINIZI_BURAYA_YAPISTIRIN` yazan yeri, Google AI Studio'dan kopyaladığınız **kendi API anahtarınızla** değiştirin.
3.  Dosyayı kaydedin. Hepsi bu kadar!
